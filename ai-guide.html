先分清楚：模型、推理強度、工作模式

這三件事常常出現在同一個選單裡，所以很容易被當成同一件事。這一章固定用同一套名稱：模型（Model）是「哪顆腦」、推理強度（Reasoning）是「這次想多久」、工作模式（Work Mode）是「現在允許 AI 做到哪一步」。

模型（Model）
哪顆腦在想。 不同模型在速度、能力、成本與長任務表現上有不同定位。
Agent（執行者）
誰在做事。 Codex / Claude Code 不只聊天，還能讀 Repo、改檔案、執行工具與測試。
推理強度（Reasoning）
這次要想多久。 同一個模型可以用不同推理投入處理簡單或複雜工作。
工作模式（Work Mode）
現在允許它做什麼。 規劃模式（Plan Mode）先研究與規劃；執行模式（Execute / Default）才進入實作。
專案規則（Rules）
做事要遵守什麼。 固定規則放在 AGENTS.md 或 CLAUDE.md，不用每次重講。

第一層：模型（Model）

先只看「這顆模型大概適合什麼」。這裡不要把規劃模式或推理強度混進來。

Claude Code：模型怎麼選

模型新手先這樣理解
Haiku快、效率高，適合明確的小任務與簡單修改。
Sonnet日常 coding 的主力，速度與能力比較平衡。
Opus複雜推理、架構、難除錯與跨檔分析。
Fable 5最難、最長時間的自主工作；適合大型調查、root cause、架構決策，不是每個小任務都需要。

GPT-5.6：Luna、Terra、Sol 怎麼分

模型定位新手先這樣理解
GPT-5.6 Luna最快、成本最低日常小問題與速度優先工作。Free / Go 的一般 ChatGPT 體驗主要由 Luna 支援。
GPT-5.6 Terra能力、速度、成本的平衡款比 Luna 更適合一般工作，又比 Sol 更偏效率；可在支援的 Work、Codex 與 API 情境使用。
GPT-5.6 Sol旗艦主力coding、研究、規劃與複雜知識工作。符合資格的付費 ChatGPT 方案以 Sol 支援 Instant、Medium、High、Extra High。
GPT-5.6 Sol Pro最高能力取向很難、很長的工作流程。ChatGPT 的 Pro 選項會使用 Sol Pro。
Terra 為什麼平常 ChatGPT 看不到？ Terra 與 Luna 不是標準 ChatGPT 對話裡可直接手動選的模型；視方案與產品而定，它們可在 Work、Codex 使用，開發者也可透過 API 使用。標準付費 ChatGPT 的主要選擇則圍繞 Sol、推理強度與 Sol Pro。
不要硬把 Claude 和 GPT 做一對一配對。 它們不是同一家公司，也不是同一套能力刻度。第一階段只要會依任務判斷「速度優先、日常主力、複雜推理、長時間高難度工作」即可。

第二層：推理強度（Reasoning）

推理強度（Reasoning）不是另一顆模型，而是這次要讓模型投入多少思考。之後全站看到「推理強度」或英文 Reasoning，指的都是這個概念。

ChatGPT 選項實際含義
Instant速度優先。符合資格的付費方案主要由 GPT-5.6 Sol 支援；Free / Go 則使用 GPT-5.6 Luna。
MediumGPT-5.6 Sol 的標準推理強度。
HighGPT-5.6 Sol 的延伸推理強度，適合較複雜工作。
Extra HighGPT-5.6 Sol 可選的最高推理強度，是否可用取決於方案。
Pro這不是單純再提高推理強度。它會改用 GPT-5.6 Sol Pro，處理最難與較長時間的工作流程。
Free / Go 的 Think 也要分清楚。 Think 是較需要思考時的選項，但目前使用 GPT-5.6 Luna，不等於付費方案的 Sol Medium / High。
不要什麼都開最高。 改一個標題不需要最高推理強度；先分析一個陌生 Repo 為什麼壞掉，才值得提高推理強度。速度、額度與任務難度要一起看。

第三層：工作模式（Work Mode）

工作模式回答的不是「哪顆模型比較強」，而是「AI 現在能不能動手改專案」。

工具規劃模式（Plan Mode）執行模式（Execute / Default）
Claude Code先讀檔、探索、研究與提出計畫，不先修改原始碼。確認方向後，才進行檔案修改、執行與驗證。
Codex先做非破壞性探索與規劃。確認方案後再真正修改專案。
opusplan 到底是什麼？ 它不是一顆叫 opusplan 的模型，也不是規劃模式（Plan Mode）本身。它是 Claude Code 的特殊模型設定：進入規劃模式時使用 Opus，進入實作時切回 Sonnet。 
模型（Model）          = 哪顆腦
推理強度（Reasoning）  = 這次想多久
工作模式（Work Mode）  = 現在能不能動手改
Agent（執行者）        = 誰去讀檔、執行工具、完成任務
專案規則（Rules）      = 專案 SOP
對新手最重要的不是記住所有型號。 真正有用的是：小任務選快的；複雜問題換強模型或提高推理強度；範圍不清楚時先用規劃模式；確認方案後再進執行模式。
