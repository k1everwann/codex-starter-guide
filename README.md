# Codex / Claude 工程入門指南

用一個已經做好的旅遊網站，理解 AI Coding 從「生成網頁」進化到真正軟體專案的基本工作流。

## 這個網站會教什麼

- Model / Agent / Mode 的差別
- Claude Code Plan Mode 與 Codex Plan / Default 概念
- Git 與 GitHub
- GitHub Pages
- Notion、README.md、AGENTS.md、CLAUDE.md 的分工
- Issue、Branch、Pull Request
- Test、Secret、Deploy、Log
- SQLite、API
- Gmail / Google Drive / Notion Connector

## 為什麼沒有先教很多語法？

目標是先建立「一個真正專案怎麼運作」的直覺。語法可以交給 AI 協助，但你仍需要理解需求、版本、資料、權限、測試與部署。

## 本機瀏覽

直接開啟 `index.html` 即可，或使用任何靜態 HTTP server。

## 發布

本專案是純 HTML / CSS / JavaScript，可以使用 GitHub Pages 發布。


## Python

本指南只教「看懂 AI 產生的 Python」所需概念：變數、List / Dictionary、if、for、function、import，以及 Error / Traceback；不把重點放在背語法。
