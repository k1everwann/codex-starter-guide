# CLAUDE.md

## Project
A dependency-free Traditional Chinese tutorial site that teaches a beginner how AI coding fits into a real software project.

## Working style
- For broad changes, plan first and identify affected sections before editing.
- Keep explanations concise, practical, and analogy-first.
- Preserve existing content unless a requested update makes it obsolete.

## UI
- Traditional Chinese only for user-facing copy.
- Minimal, editorial visual style.
- Mobile-first and accessible.
- No unnecessary animation or third-party UI libraries.

## Safety
- Never commit secrets or credentials.
- Do not add real personal email contents or private connector data to examples.
