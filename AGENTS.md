# AGENTS.md

## Purpose
This repository is a beginner-friendly Traditional Chinese tutorial site about Codex, Claude Code, GitHub, Notion, SQLite, APIs, connectors, and software-engineering workflow.

## Rules
- UI copy must stay in Traditional Chinese.
- Keep the site dependency-free: plain HTML, CSS, and JavaScript only.
- Preserve mobile responsiveness.
- Do not introduce a framework or build step unless explicitly requested.
- Do not remove the official-source links without replacing them with newer official sources.
- Explain concepts with beginner-friendly analogies before technical detail.
- Avoid exposing API keys, tokens, credentials, or personal data.

## Validation
After edits:
- Ensure `index.html`, `styles.css`, and `script.js` load without missing local references.
- Check that all navigation anchors point to existing section IDs.
- Check that the page remains usable at mobile widths.
